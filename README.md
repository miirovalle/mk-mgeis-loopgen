# MK MGEIS Loop Generator

Two things live here:

1. **`loopgen.py` (v3)** — arranges 4 / 8 / 16 bar MIDI loops from a key-sorted loop
   library, using per-bar chord estimation so the parts that get combined actually
   agree harmonically.
2. **`ios/`** — a native Swift port packaged as an **AUv3 MIDI processor** plus a
   host app, built into an unsigned `.ipa` by GitHub Actions.

## Python generator (v3)

Requires Python 3.10+ and `mido`.

```
pip install mido
python loopgen.py --list-keys
```

The library is a folder of key folders (`A minor/`, `C major/`, ...) each holding
`.mid` files. Build one from a flat folder of loops with `slice_midi.py` and
`organize_by_key.py` from the original workflow, or point `--library` at your own.

### What v3 adds over v2

* **Per-bar chord estimation** for every loop, then **harmonic-compatible part
  picking** — measured 0.74 mean chord agreement between chosen parts versus 0.44
  for random pairing.
* **Form templates**: `--form auto|loop|build|song|dropout`.
* **Relative-key pooling**: A minor may borrow loops filed under C major (same
  scale). Disable with `--no-relative`.
* **Section markers** and a **key signature** in the output MIDI.
* `--version`.

### Usage

```bash
python loopgen.py --key "A minor" --bars all                 # 4, 8 and 16 bars
python loopgen.py --key "A minor" --bars 16 --form song --count 3 --seed 7
python loopgen.py --all-keys --bars 8 --variation per_phrase --recipe
python loopgen.py --key "C major" "F minor" --stems --recipe
```

| Flag | Meaning |
|---|---|
| `--bars 4 8 16` / `all` | lengths to generate (multiples of 4) |
| `--form` | `auto`, `loop`, `build`, `song`, `dropout` |
| `--variation` | `per_phrase` (default), `per_section`, `fixed` |
| `--parts` | `bass,chords,melody` by default; also `arp`, `pad`, `perc` |
| `--seed` | deterministic output |
| `--min-fit` | minimum share of notes inside the key (default 0.85) |
| `--stems` | write one file per part |
| `--recipe` | write a `.recipe.json` naming every source slice |

Arrangement: `A` intro (bass + chords) → `B` full → `C` full with a fill in bar 12
→ `D` full with the last bar dropped. Output is exactly 4.00 / 8.00 / 16.00 bars.

## iOS: AUv3 MIDI generator

`ios/Sources/Shared/Generator.swift` is the native engine: it generates an in-key
loop (bass, chords, melody) with a diatonic progression — i–VI–III–VII in minor,
I–V–vi–IV in major — arranged in 4-bar phrases with an intro, a fill and a closing
break, and is deterministic per seed.

* **`LoopGenAU`** — AUv3 **MIDI processor** (`type aumi`, subtype `lpg3`). It reads
  the host's beat position, quantises to 16ths and streams note-on/note-off events
  through `midiOutputEventBlock`, so it plays in sync in AUM, Drambo, AUM-style
  hosts, GarageBand, etc. Parameters: Root, Scale, Bars, Seed.
* **`LoopGen`** — host app: pick key/scale/bars/seed, see the progression, render
  and share a `.mid` file.

### Build the unsigned IPA

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
from `ios/project.yml` — there is no checked-in `.xcodeproj`.

```bash
brew install xcodegen
cd ios && xcodegen generate
xcodebuild -project LoopGen.xcodeproj -scheme LoopGen \
  -configuration Release -sdk iphoneos \
  -destination 'generic/platform=iOS' \
  -archivePath build/LoopGen.xcarchive archive \
  CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO
```

CI does this on a macOS runner and uploads `LoopGen-unsigned.ipa`
(`.github/workflows/ios.yml`). The IPA is **unsigned**, so install it with
Sideloadly / AltStore / Xcode (which re-sign it with your own Apple ID).
